## 最短真机验收流程

1. 保存原文档，关闭目标 SketchUp，按安装说明预览并安装；保存备份路径。首次验收使用明确的新建空白测试模型。
2. 重开宿主，确认桥接自动启动；运行 `doctor --year YEAR --live`。从客户端调用实际 MCP 的 `get_supported_versions`、`get_capabilities(runtime=queue)` 和 `get_model_info(runtime=queue)`，核对真实年份与当前文档。若客户端只暴露 Gateway，按 Skill 的 discover/connect 路线发现工具。
3. 使用 README 中已明确长宽高及基底标高的建筑体块提示词。通过服务器的会话/任务合约创建，读取原生包围盒和视口证据，核对 10 m × 8 m × 3 m、标高 0 与实际单位。不能用 mock 图片代替真机证据。
4. 经用户同意，把测试体块高度改成 4 m，确认目标对象唯一、无无关对象变化；按服务器要求完成现有模型编辑审查。检查一次 Undo 的行为和撤销后状态。
5. 指定一个新的测试输出路径，按公开工作流保存。只有支持且获准的生命周期操作才重开文件，不能丢弃未保存修改。确认可编辑群组/组件、对象身份和参数绑定的实际保留情况；普通几何不能冒充持久参数化。
6. 提交无可靠尺度的单张图片，要求 AI 先展示缺失项和假设。确认未获用户同意时不执行实时建模；同意明确方案后再做白模并核对尺寸。
7. 2020 上提交新版环境/PBR 操作，应在修改模型前报不支持；同一 2020 模型普通颜色/贴图应正常。2026 的相应功能需单独验证。
8. 若两个年份都安装，分别连接并检查模型。在隔离测试队列中检查错误年份/旧协议请求被拒绝；不要改动正在工作的队列或复制旧锁来制造故障。原进程退出、延迟响应等情况先查原任务状态，不直接重放创建。

庭院示例的所有尺寸均为示例设计数据。实际使用前必须展示给用户确认；示例无 `reset` 操作，但仍会新增对象。它含平台、园路、花池、廊架等组合体块，不代表完整施工构造或可一键重建的园林参数系统。
