# 建筑建模

从建筑用途和成果要求确定范围：体量概念、方案构件、已有模型修改，或来自平立剖的复现。整理外轮廓、楼层与标高、层高、墙/板厚度、开口定位和尺寸、屋面形式与坡度、楼梯连接，以及要保留的现状对象。用户只提供总体尺寸不代表已批准未展示的构造尺寸。

把设计关系写成可追溯的参数依赖，例如“总高由各层层高之和得出”“门洞顶标高由楼面与门高相加”。说明原点、+Z 向上、墙线在中线还是内/外边；不要在同一建筑中静默混用。结构开口与装饰线、真实孔洞与贴图分别表达。

## 创建

先建立轮廓、楼层、主要竖向关系和屋面白模。检查范围、总高、相邻构件连接和主要开口位置，再添加墙板、门窗、楼梯、栏杆等。复杂系统优先原生群组/组件，重复门窗和柱复用定义；需要单独调整时先明确单实例/全部关联实例范围。

通用构件 task 的门窗等配方有固定设计和范围限制。读取 `discover/tasks` 的 `fixed_design`、`parameter_rules` 与完整示例；若用户要求与配方不符，使用支持的 DSL/受审查编辑，或报告具体缺口，不能悄悄替换为配方默认造型。

持久记录构件参数及生成版本，关联服务器提供的创建任务/DesignIntent/参数基线。参数变更重新计算依赖几何，并验证保留对象没有变化。已有人工修改与参数基线冲突时，先展示差异，不用重新生成把人工编辑抹掉。

## 验证

检查总长宽高、楼层标高、墙板厚、开口净尺寸及位置；需要真实洞口的地方检查孔洞与封口状态。检查反面、重复面、错位、上下层穿插和未闭合边界。区分要求为实体的封闭构件与本来开放的薄面；不要要求整个建筑外壳都成为一个实心体。

保持门窗、楼梯、栏杆和屋面之间的空间关系。视口至少覆盖平面、关键立面/剖面关系与透视整体。清楚标记没有图纸支持的背面与隐蔽部分。

本技能产生建模与设计表达。厚度、跨度、踏步、护栏和防火尺寸如为建议，先确认；如用户需要规范结论，应另外读取其指定地区、用途及适用版本的规范/计算依据。没有这类证据时不声称满足结构、消防或施工要求。
